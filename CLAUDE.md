# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

**Pintech OS** – ERP web para Pintech Colombia S.A.S (pinturas industriales).
Laravel 13 + React 19 + Inertia.js v3 + TypeScript + Tailwind CSS v4 + PostgreSQL 16.

Covers plant operations end to end: raw material inventory (FIFO), formulas, production orders,
finished goods inventory, pricing/costing, quotations, sales orders, clients, paint development
requests and QR product documentation.

## Architecture

### Request Flow

```
Route (routes/web.php, role: middleware)
  └─ Form Request  (validation + authorize())
       └─ Controller (thin: authorize, delegate, Inertia::render)
            ├─ Filter   (index listings: search/status/date-range → Builder)
            ├─ Action   (single write use case, e.g. CompleteProductionOrderAction)
            └─ Service  (reusable domain logic, injected by constructor)
                 └─ DecimalCalculator (bcmath) for every money/quantity computation
```

Every layer lives under `app/`. Controllers never contain business logic; Actions orchestrate one
use case inside a transaction; Services hold logic shared by several Actions/Controllers.

### Key Backend Directories

- `app/Actions/Production/` — production order use cases (`Create`, `Start`, `SubmitForReview`,
  `RejectReview`, `Complete`, `Cancel`, `ConsumeRemnant`, plus `Build*Action` read-model builders
  for the show page, PDF and Excel exports)
- `app/Actions/Fortify/`, `app/Actions/Quotations/`
- `app/Filters/` — `QueryFilter` base + one filter per listing (see *Listing pattern* below)
- `app/Services/` — `InventoryService`, `FormulaService`, `QuotationService`, `SalesOrder`-related,
  `AlertService`, `DashboardService`, `TimezoneService`, `DecimalCalculator`,
  `RawMaterialReferencePriceService`, `VariantPricingService`, `VariantSalesPriceService`,
  `ProductionCostRecalculationService`, `PriceListService`, `QrImageService`,
  `ProductDocumentService`, `QualityInspectionCertificateService`, `SignatureOptimizerService`,
  `WarehouseContextService`, `PaintDevelopmentRequestService`
  - `Services/Inventory/` — `FifoStockAllocatorService`, `InventoryBatchService`,
    `InventoryMovementService`
  - `Services/FinishedInventory/` — `FinishedInventoryMovementService`,
    `FinishedProductBatchStockService`
  - `Services/Pricing/` — `ProductionCostCalculatorService`
- `app/Http/Requests/{Domain}/` — one directory per domain, including `Index*Request` classes whose
  `rules()` define the filterable query params
- `app/Policies/` — one per aggregate; authorization is by role, not by granular permission
- `app/Enums/` — every DB enum has a PHP enum with a `label()` method (translated via `__()`)
- `app/Support/EnumOptions.php` — `EnumOptions::for(SomeEnum::cases())` builds
  `{value,label}[]` arrays for React `<Select>` props
- `app/Concerns/` — `DeterminesPriceRefresh`, `RedirectsWithContext` (safe `return_to` redirects),
  validation rule traits
- `app/Exceptions/InsufficientStockException.php`
- `app/Console/Commands/CheckExpiryAlertsCommand.php`; ad-hoc commands and the schedule live in
  `routes/console.php` (`activitylog:clean` 03:00, `alerts:check-expiry` 06:00, both in plant TZ;
  `costs:recalculate-product` for cost backfills)

### Frontend Structure

```
resources/js/
├── pages/           # Inertia pages, PascalCase paths matching Inertia::render() strings
├── components/      # Shared components + one folder per domain (production/, quotations/, ...)
│   └── ui/          # shadcn/ui (Radix)

├── layouts/, lib/, types/
```

Shared building blocks worth reusing instead of re-implementing: `DataTableFilters` +
`useFilters` (listings), `TableActions` (row actions), `FormattedDate`/`FormattedNumber`
(locale + plant timezone), `DetailPageHeader`/`DetailPageNav`, `WarehouseSelector`,
`FlashMessages`, `AlertToastNotifier`.

### Roles & Authorization

Four Spatie roles: `admin` (full access), `produccion` (plant operations), `comercial`
(quotations, clients, prices), `operador` (shop-floor execution of production orders).
Routes are grouped by the `role:` middleware (`App\Http\Middleware\CheckRole`, comma-separated
roles), and controllers additionally call Policies via `authorize()` / `$request->user()->can()`.
Pass a `can` array in Inertia props so the UI hides actions the user cannot perform.

## Key Business Rules

### Decimal Precision (CRITICAL)
- **Never compute money or quantities with PHP floats.** Use `App\Services\DecimalCalculator`
  (bcmath, string in/string out, default scale 4) for every add/sub/mul/div/compare on costs,
  prices, stock and formula quantities. `ext-bcmath` is a hard requirement.

### Inventory & Costing
- **FIFO costing**: batches are consumed strictly oldest-first via `FifoStockAllocatorService`
- **Batch traceability**: every inventory movement MUST reference an `InventoryBatch`
- **Reference price**: recalculated by the async job `RecalculateRawMaterialReferencePrice`;
  never compute the weighted average synchronously on a hot path
- **No name on raw materials**: `raw_materials` has NO `name` column — identification is by `code`
  only (privacy policy). Search filters therefore target `code`.
- Deactivation is logical (`is_active`); never hard-delete records that historical costs reference

### Production Orders
- Numbering `OP-YYYY-XXXX` with yearly reset, serialized by
  `pg_advisory_xact_lock` (Quotations and paint development requests use their own lock keys).
  Guard advisory locks with `DB::connection()->getDriverName() === 'pgsql'` so SQLite tests pass.
- Lifecycle: `pending` → `in_progress` → `pending_review` → `completed`, plus `cancelled`.
  Inventory is deducted on completion; review can be rejected back to the operator.
- `production_order_line_adjustments` record real vs planned consumption;
  `production_order_packaging_plan` defines variant-level output
- Leftover product becomes a `ProductionRemnant` (`available` → `partially_consumed` → `consumed`)
  that a later order can consume before pulling fresh raw material

### Pricing & Costs
- Unit production cost: `(Total Raw Material Cost / Total Gallons Produced) × Presentation Size
  + Packaging Cost` (`ProductionCostCalculatorService`)
- `VariantPricingService` / `VariantSalesPriceService` derive sale prices from cost + margin;
  calculated prices are read-only in the UI and require price authorization to change
- `price_lists` is historical — never mutate past records; `production_costs` snapshots the cost at
  order completion

### Timezone
- App timezone is UTC; the plant timezone is `config('app.plant_timezone')` (`America/Bogota`).
  Use `TimezoneService` for anything user-facing (PDFs, exports, reports) and the
  `FormattedDate`/`date-time-helpers` utilities on the frontend. Scheduled tasks pin the plant TZ.

### Alerts
- `AlertService` generates low-stock, expiry and price-variation alerts; `alerts:check-expiry`
  runs daily. Alerts use the `AlertType` / `AlertSeverity` enums and surface via `AlertToastNotifier`.

## Key Patterns

**Listing pattern (full stack)** — follow this for every index page:
1. `Index{Domain}Request` validates the allowed query params in `rules()` and authorizes via policy
2. `{Domain}Filter extends QueryFilter` declares `protected array $filterable` and one protected
   method per param; use the helpers `applySearch()` (LOWER LIKE, supports `relation.column`),
   `applyDateRange()`, `applyExact()`, `isValidInteger()` — never write raw `ILIKE`
3. Controller: `(new XFilter($request))->apply(Model::query())->with(...)->paginate(15)
   ->onEachSide(1)->withQueryString()` and pass `filters => $request->validated()` back to Inertia
4. Frontend: `useFilters({ routeUrl, initialFilters })` + `<DataTableFilters />`
   (debounced, `preserveState`, `replace`)

**Controllers**: constructor-inject Actions/Services as `private readonly`; `Inertia::render()`
with PascalCase page paths; pass `can` hints and `EnumOptions::for(...)` option lists.

**Form Requests**: domain-organized; authorization in `authorize()`; always `$request->validated()`,
never `$request->all()`.

**Models**: `@property` PHPDoc, `casts()` with enum casts, `scopeActive()`/domain scopes,
Spatie `getActivitylogOptions()` on auditable models.

**Files**: `declare(strict_types=1);` at the top of new PHP files (matches existing code).

## Coding Standards

- **Code in English** (classes, methods, variables, DB columns). User-facing strings and inline
  comments are Spanish; translations live in `lang/es`, `lang/en`, `lang/es.json`.
- **PHP**: PSR-12 via Laravel Pint. **SQL**: database-agnostic (`LOWER()` not `ILIKE`).
- **Git**: Conventional commits (`feat:`, `fix:`, `docs:`, `style:`, `refactor:`).
  Branches: `main` (prod), `develop` (integration), `feature/PT-XXX-desc`.
- **Naming**: PascalCase classes, camelCase methods/variables, snake_case DB columns.

### UI Standards (MANDATORY)

Use the `TableActions` component for ALL table row actions: icons only (lucide-react), tooltips
mandatory, `sr-only` text included. Colors: View (outline), Edit (warning/amber), Delete
(destructive/red). Order: View → Edit → Delete.

## AI Rules (CRITICAL)

- ALWAYS use Inertia helpers (`useForm`, `Link`, `router`); never hand-rolled `useState` forms or
  `fetch` where Inertia has a solution
- NEVER hardcode URLs in the frontend — always import Wayfinder helpers from `@/routes` or
  `@/actions` (e.g. `href={productsIndex().url}`)
- Initialize `useForm` directly with default values from props
- Seeders MUST be idempotent (`updateOrCreate` / `firstOrCreate`); gate mock data with
  `app()->environment('local', 'testing')`
- Reuse the existing Filter/Action/Service/DecimalCalculator patterns instead of introducing new ones
